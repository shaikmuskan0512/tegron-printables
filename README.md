# ☀ Tegron Printables

### Learn • Play • Grow

Tegron Printables is a full-stack printable marketplace platform
where users can discover printable products, explore categories,
submit ideas and questions, and access their personal dashboard.

## ✨ Features

- Browse and search printable products
- Category filtering
- Etsy integration
- User authentication
- Member dashboard
- Submit product ideas and questions
- Admin dashboard
- Product and category management
- Cloudinary image uploads
- MongoDB database

## 🛠 Tech Stack

Frontend:
React • TypeScript • Vite • Tailwind CSS

Backend:
Node.js • Express • TypeScript

Database:
MongoDB • Mongoose

Authentication:
JWT • bcrypt

Images:
Cloudinary

## 🚀 Getting Started

### Backend

cd backend
npm install
npm run dev

### Frontend

cd frontend
npm install
npm run dev

Frontend: http://localhost:5173
Backend: http://localhost:5000

## 🔐 Environment Variables

Create your own `.env` files using:

backend/.env.example
frontend/.env.example

Never commit real credentials or API keys.
